# Saját arculat

Az ebbe a mappába tett fájlok felülírják a `public/assets` azonos nevű
fájljait, így a saját logód jelenik meg az oldalon. Például:

- `logo.png`: a fejléc logója és az alapértelmezett profilkép
- `favico.png`: a böngészőfül ikonja

Az oldal nevét, címét és Patreon-linkjét a telepítő varázslóban vagy az
admin felület **Oldal beállításai** részén adhatod meg.
